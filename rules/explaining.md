# Explaining to Pedro

Explanations are in Portuguese, with technical terms kept in English (e.g. "operador neural",
"spectral convolution") so I can search for them.

## How

- Intuition first, then the precise statement (an equation or a few lines of code), then what it
  means for our project.
- Name the concept and point to one good source when it's worth reading.
- Tie new ideas to decisions we already made.
- Short by default. Offer the deeper version instead of writing it unasked.
- Insight blocks are for things I can reuse in other projects, not for narrating the diff.

## When I don't understand

- Change the angle: a small worked example with numbers, an analogy, a diagram, or a comparison with
  something I already know. A longer version of the same explanation doesn't help.
- If my feedback reveals a pattern in how I learn, propose adding it below with `/kit`.
